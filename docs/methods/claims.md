# Storage claims

Candidate claims come from verified contract source, contract metadata, marketplace descriptions, project websites and
third-party directories. Each candidate retains a quotation and source. Directory descriptions are third-party text;
source comments may describe implementation details rather than make a collection-wide marketing promise. Quotes and
automated candidate matches therefore require contextual interpretation.

Pointer location, the location of separately stored artwork bytes, and the power to change a pointer are separate facts.
An HTTP token URI does not by itself disprove an on-chain artwork-data claim. The public claims tables retain provenance
so these distinctions can be checked. See [Methods](../../METHODS.md), `data/claims/` and `data/mutability/`.
