# Top-100 collection panel

## Ranking and independent cross-check

The panel uses CryptoSlam’s all-time Ethereum owner-to-owner sales ranking in historical USD, whose source interface excludes wash sales. Duplicate labels for the same reported contract are removed, retaining the higher source total. Source-listed companion contracts remain part of the collection identity. The 100th distinct collection is source rank 105. The source totals are not independently reconstructed trade by trade. OpenSea all-time ranking pages provide a separate contract-overlap check; missing coverage is unknown, not zero sales. See `data/top100/ranking.json` and `ranking_crosscheck.json`.

## Census, liveness and control method

At least three token units per collection are sampled, 306 across source-listed contracts. 888 Inner Circle exposes two distinct IDs; a second fungible unit of ID 888 supplies its third unit. Expired or burned samples are replaced only after ownership checks. Metadata must parse as JSON; media must have recognizable bytes or content type. HTTP negatives require retries in both passes; content-addressed negatives require multiple gateways. Timeouts, rate limits and bot walls remain unknown. These short-window delivery observations do not establish permanent content loss.

The strict on-chain test requires metadata and every declared sampled media field on-chain, without external loading references. CryptoPunks uses its separately sealed data renderer as a documented legacy adapter. This route test does not inventory alternate recovery contracts or prove browser rendering. HTTP dependence excludes recognized IPFS/Arweave gateways. IPFS and HTTP counts can overlap. Single-key repointing counts live EOA URI, renderer or upgrade power; data-only edits remain separate.

The snapshot has six strict on-chain collections, 13 dead/degraded metadata or primary-image delivery paths, 52 one-key repointable collections and 49 HTTP-dependent collections. Four remain unknown. Recount against `data/top100/top100.csv` and `summary.json`.

## Presentation review

Mooncats (#68) is the source-ranked Wrapped MoonCatsRescue contract, not the original rescue contract. Owned IDs 4, 8 and 9 return empty strings from successful `tokenURI` calls. Its sampled wrapper metadata is unavailable; this does not show that the legacy art is dead. The exported reason is `empty-tokenuri`, distinct from the fallback ERC-1155 `uri` revert.

Art Gobblers (#94) is degraded: owned IDs 1 and 5000 return metadata and images; owned ID 10000 returns metadata HTTP 404 in both passes. NFT Worlds (#30) has repeated metadata DNS failures for all three samples. CryptoPunks (#2) and Autoglyphs (#69) pass the strict route test; BAYC (#1) uses IPFS for metadata and images.

## Public evidence

`site/data/top100-evidence/<contract>.json` contains redacted sample outcomes, control details and saved-packet hashes. Raw bodies are omitted. Withheld origins are unnamed. Offline builders require an operator-supplied redaction list through `WITHHELD_HOSTS_FILE`; that list is not distributed.
