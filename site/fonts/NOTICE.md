# Self-hosted fonts

- Archivo variable Latin (`archivo-var-latin.woff2`), Omnibus-Type. SIL Open Font License 1.1; see `OFL.txt`.
- Silkscreen Regular (`silkscreen-regular.ttf`), The Silkscreen Project Authors. SIL Open Font License 1.1; see `Silkscreen-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/silkscreen (downloaded 2026-10-22).

Silkscreen is used only for display headings, large figures and short controls. Reading text uses Archivo.
